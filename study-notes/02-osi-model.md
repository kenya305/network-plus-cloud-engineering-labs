# Network+ N10-009 Study Notes: OSI Model

## Video Topic
OSI Model

## Summary
The OSI Model stands for Open Systems Interconnection. It is a reference model used to describe how data moves across a network.

The OSI model helps IT professionals communicate clearly when discussing networking concepts and troubleshooting issues.

## The Seven OSI Layers

| Layer | Name | Key Concepts |
|---|---|---|
| 7 | Application | HTTP, HTTPS, FTP, DNS, user-facing applications |
| 6 | Presentation | Encryption, decryption, formatting, SSL/TLS |
| 5 | Session | Starts, manages, and ends sessions |
| 4 | Transport | TCP, UDP, port numbers |
| 3 | Network | IP addresses, routing, subnet masks |
| 2 | Data Link | MAC addresses, switches, Ethernet frames |
| 1 | Physical | Cables, fiber, wireless signals |

## Key Takeaways
- Layer 1 deals with physical signals, cables, fiber, and wireless.
- Layer 2 deals with MAC addresses and switching.
- Layer 3 deals with IP addresses and routing.
- Layer 4 deals with TCP, UDP, and port numbers.
- Layer 5 manages communication sessions.
- Layer 6 handles encryption, decryption, and formatting.
- Layer 7 includes application protocols like HTTP, HTTPS, FTP, and DNS.

## Cloud Engineering Connection
The OSI model is important for cloud engineering because cloud professionals troubleshoot network connectivity, firewall rules, DNS, routing, VPNs, load balancers, and application access.

## Troubleshooting Examples
- Bad cable: Layer 1
- Switch issue: Layer 2
- Wrong IP address or subnet mask: Layer 3
- Blocked TCP port: Layer 4
- Session timeout: Layer 5
- SSL/TLS certificate issue: Layer 6
- Website or DNS issue: Layer 7
