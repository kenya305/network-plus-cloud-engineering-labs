# Network+ N10-009 Study Notes: Fiber Connectors

## Video Topic

Fiber Connectors

## Summary

Fiber-optic networks use different connector types.

The connector must match the interface on the network device.

Common fiber connectors include:

- SC
- LC
- ST
- MPO
- MTP

This lesson explains the shape, locking mechanism, fiber count, and common use of each connector.

---

## Why Fiber Connector Types Matter

Fiber-optic devices may use different connector types.

Before connecting fiber-optic cabling, verify:

- Connector type
- Device interface
- Fiber type
- Number of fibers
- Transmit and receive requirements
- Locking mechanism
- Equipment compatibility

### Key Takeaway

```text
The fiber connector must match the device interface.
```

---

## SC: Subscriber Connector

SC stands for:

```text
Subscriber Connector
```

SC may also be called:

```text
Square Connector
Standard Connector
```

The SC connector has a square shape.

It uses a push-and-lock mechanism.

### SC Connection Process

```text
Push connector into interface
→ Connector snaps into place
→ Pull connector slightly to unlock and remove
```

### SC Characteristics

| Feature | SC Connector |
| ------- | ------------ |
| Full name | Subscriber Connector |
| Alternate names | Square Connector, Standard Connector |
| Shape | Square |
| Locking method | Push-and-lock |
| Fiber count | Commonly one fiber per connector |
| Pairing | Often used in pairs for transmit and receive |

### Key Takeaway

```text
SC = Square connector with push-and-lock mechanism
```

---

## LC: Local Connector

LC stands for:

```text
Local Connector
```

LC may also be called:

```text
Lucent Connector
Little Connector
```

The LC connector is smaller than the SC connector.

It uses a clip on top to lock into place.

### LC Connection Process

```text
Push connector into interface
→ Clip locks connector into place
→ Press clip down to release and remove
```

### LC Characteristics

| Feature | LC Connector |
| ------- | ------------ |
| Full name | Local Connector |
| Alternate names | Lucent Connector, Little Connector |
| Size | Smaller than SC |
| Locking method | Clip-lock |
| Fiber count | Commonly one fiber per connector |
| Pairing | Often used in pairs for transmit and receive |

### Key Takeaway

```text
LC = Little connector with clip-lock mechanism
```

---

## ST: Straight Tip

ST stands for:

```text
Straight Tip
```

The ST connector uses a bayonet-style locking mechanism.

A bayonet connection is inserted and twisted into place.

### ST Connection Process

```text
Push connector into interface
→ Twist connector slightly
→ Connector locks into place
```

To remove the connector:

```text
Reverse the twist
→ Pull connector out
```

### ST Characteristics

| Feature | ST Connector |
| ------- | ------------ |
| Full name | Straight Tip |
| Shape | Round |
| Locking method | Bayonet twist-lock |
| Protective component | Ferrule |
| Common use | Fiber-optic connections requiring a secure twist-lock |

### Key Takeaway

```text
ST = Straight Tip connector with twist-lock mechanism
```

---

## MPO: Multi-Fiber Push On

MPO stands for:

```text
Multi-Fiber Push On
```

MPO combines multiple fiber strands into one connector.

The lesson shows an MPO connector containing:

```text
12 fibers
```

This allows more fiber connections to fit inside a smaller physical space.

### MPO Connection Process

```text
Push connector into interface
→ Connector locks into place
→ Pull connector slightly to unlock and remove
```

### MPO Characteristics

| Feature | MPO Connector |
| ------- | ------------- |
| Full name | Multi-Fiber Push On |
| Fiber count | Commonly multiple fibers in one connector |
| Example from video | `12` fibers |
| Locking method | Push-and-lock |
| Main benefit | High-density fiber connectivity |
| Common use | Data centers and high-density fiber environments |

### Key Takeaway

```text
MPO = Multiple fibers inside one compact connector
```

---

## MTP

MTP is a branded version of the MPO connector.

The term is commonly associated with Corning.

### Key Takeaway

```text
MTP is a branded MPO-style connector.
```

---

## Fiber Connector Pairing

Some fiber connectors are commonly used in pairs.

One connector is used for:

```text
Transmit
```

The other connector is used for:

```text
Receive
```

### Common Paired Connectors

| Connector | Commonly Used in Pairs |
| --------- | ---------------------- |
| SC | Yes |
| LC | Yes |

---

## Locking Mechanisms Comparison

| Connector | Locking Mechanism |
| --------- | ----------------- |
| SC | Push-and-lock |
| LC | Clip-lock |
| ST | Bayonet twist-lock |
| MPO | Push-and-lock |

### Why Locking Mechanisms Matter

Fiber connections may be installed inside crowded racks.

Without a locking mechanism, a cable could be accidentally pulled out of the interface.
