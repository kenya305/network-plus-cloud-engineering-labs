# Lab 01: OSI Model Home Network Mapping

## Objective

Map a basic home network connection to the seven layers of the OSI model.

## Scenario

A laptop connects to a website using Wi-Fi through a home router.

## OSI Layer Mapping

| OSI Layer | Home Network Example |
|---|---|
| Layer 7: Application | Web browser accessing a website |
| Layer 6: Presentation | TLS encryption for HTTPS |
| Layer 5: Session | HTTPS session between browser and web server |
| Layer 4: Transport | TCP port 443 |
| Layer 3: Network | IP address and router forwarding traffic |
| Layer 2: Data Link | MAC address and local Wi-Fi/Ethernet communication |
| Layer 1: Physical | Wi-Fi signal or Ethernet cable |

## What I Learned

The OSI model helps break network communication into layers, making troubleshooting more structured and easier to explain.

## Cloud Engineering Connection

Cloud engineers use these same concepts when troubleshooting virtual networks, firewalls, routing tables, DNS, load balancers, VPNs, and secure web applications.
